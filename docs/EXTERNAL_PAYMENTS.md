# Nova AI: API пополнения баланса для партнёров

С помощью этого API ваш сервис (бот, приложение, сайт) пополняет баланс пользователя Nova. Вы создаёте платёж и показываете пользователю ссылку или QR для оплаты по СБП. Как только пользователь оплатит, Nova сама зачислит ему искры.

## Доступ

| | |
|---|---|
| Адрес API | `https://24nova-ai.ru/api/v1/external` |
| Авторизация | заголовок `Authorization: Bearer <ваш токен>` |
| Формат | JSON, UTF-8 |

Токен выдаём мы. Храните его только на своём сервере, не передавайте его в браузер или мобильное приложение.

## Как проходит оплата

1. Ваш сервер создаёт платёж: `POST /payments`.
2. Вы показываете пользователю QR из `qr_url` и кнопку «Оплатить» (`payment_url`).
3. Пользователь оплачивает по СБП.
4. Ваш сервер раз в 5–10 секунд запрашивает статус (`GET /payments/{transaction_id}`). Когда придёт `"paid": true`, искры уже зачислены пользователю.

## 1. Создать платёж

`POST /payments`

```json
{
  "transaction_id": "3f1c2a9e-6b7d-4e21-9c55-0d8a1b2c3d4e",
  "user_id": 123,
  "amount_rub": 500
}
```

| Поле | Тип | Описание |
|---|---|---|
| `transaction_id` | UUID | Ваш уникальный id операции. Генерируйте новый UUID на каждый платёж. |
| `user_id` | целое > 0 | id пользователя в Nova. |
| `amount_rub` | целое | Сумма в рублях, от 100 до 500 000. |

Запрос с тем же `transaction_id` можно безопасно повторить, например после таймаута. Второй платёж не создастся: вернётся уже существующий. Если с тем же `transaction_id` придут другой `user_id` или `amount_rub`, ответ будет `409`.

Пример:
```sh
curl -X POST https://24nova-ai.ru/api/v1/external/payments \
  -H "Authorization: Bearer $NOVA_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"transaction_id":"3f1c2a9e-6b7d-4e21-9c55-0d8a1b2c3d4e","user_id":123,"amount_rub":500}'
```

## 2. Узнать статус

`GET /payments/{transaction_id}`

```sh
curl https://24nova-ai.ru/api/v1/external/payments/3f1c2a9e-6b7d-4e21-9c55-0d8a1b2c3d4e \
  -H "Authorization: Bearer $NOVA_TOKEN"
```

## Ответ (одинаковый для обоих методов)

```json
{
  "transaction_id": "3f1c2a9e-6b7d-4e21-9c55-0d8a1b2c3d4e",
  "user_id": 123,
  "amount_rub": 500,
  "sparks": 500,
  "status": "pending",
  "paid": false,
  "payment_url": "https://go.pay.hot/pay/...#token=...",
  "qr_url": "https://go.pay.hot/pay/...#token=...",
  "created_at": "2026-11-10T17:58:43.961002Z",
  "paid_at": null
}
```

| Поле | Описание |
|---|---|
| `status` | `pending` — ждём оплату, `succeeded` — оплачено, `failed` — ошибка оплаты, `canceled` — отменён или не оплачен за 24 часа |
| `paid` | `true`, когда платёж оплачен и искры зачислены |
| `sparks` | Сколько искр получит пользователь, бонусы уже учтены |
| `payment_url` | Страница оплаты. Есть только пока `status = pending` |
| `qr_url` | Ссылка, из которой нужно нарисовать QR-код. Есть только пока `status = pending` |
| `paid_at` | Время оплаты |

**Что показать пользователю:** QR-код из `qr_url` и кнопку «Оплатить» со ссылкой `payment_url`. На телефоне хватит одной кнопки. Пользователь попадает на страницу оплаты по СБП.

Ссылка на оплату действует около 20 минут. Если пользователь не успел оплатить, создайте новый платёж с новым `transaction_id`.

**Статус:**
- После оплаты статус меняется в течение 30 секунд.
- `succeeded`, `failed` и `canceled` — окончательные статусы, после них статус больше не меняется, опрашивать дальше не нужно.
- Неоплаченный платёж закрывается как `canceled` через 24 часа.

## Ошибки

Тело ошибки: `{"detail": "текст"}`.

| Код | Причина | Что делать |
|---|---|---|
| `401` | Нет токена или токен неверный | Проверьте заголовок `Authorization` |
| `404` | Пользователь не найден или заблокирован; платёж не найден | Проверьте `user_id` / `transaction_id` |
| `409` | Этот `transaction_id` уже использован с другим пользователем или суммой | Создайте новый `transaction_id` |
| `422` | Неверные поля: не UUID, сумма вне диапазона 100–500 000 | Исправьте запрос |
| `502` | Платёжная система не создала платёж | Повторите запрос с тем же `transaction_id` через несколько секунд |
| `503` | Приём оплаты временно отключён | Повторите позже |
