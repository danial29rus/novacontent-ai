# Nova Content AI

MVP собственной AI-платформы для создания контента. Пользователь получает доступ к сервису и лимит действий — не API-ключ, не чужой аккаунт и не «баланс ChatGPT».

## Что работает

- регистрация и вход с HTTP-only сессией;
- стартовый тариф и журнал лимитов в SQLite;
- самостоятельные проекты с отдельной памятью бренда и историей;
- готовые контент-паки и конструктор собственных паков внутри проекта;
- Пост-студия, Контент-план, Редактор тона и общий AI-ассистент;
- библиотека с историей материалов;
- отдельный просмотр агрегированной статистики для роли `admin`;
- черновые страницы документов;
- серверный адаптер к OpenAI-совместимому AI API с пулом резервных ключей.

Пока не подключены: реальные платежи, файлы, magic link/Telegram-вход, полноценный CRUD тарифов/пользователей и production-хранилища/лимитеры.

## Локальный запуск

Нужен Python 3.11+; внешние зависимости не требуются.

```bash
cd novacontent-ai
cp .env.example .env
python3 server.py
```

Откройте `http://localhost:4173`. База `nova.db` создастся автоматически. На локальном HTTP оставьте `COOKIE_SECURE=false`; в production с HTTPS установите `COOKIE_SECURE=true`.

Без `AI_API_URL`, `AI_API_KEYS` и `AI_MODEL` сервис использует явно локальный шаблонный генератор, чтобы можно было проверить весь пользовательский поток. Это не внешний AI.

## Подключение AI

Перенесите значения из `.env.example` в секреты окружения вашего сервера:

```dotenv
AI_API_URL=https://provider.example/v1/chat/completions
AI_API_KEYS=primary-server-key,backup-server-key
AI_MODEL=provider-model-name
# Необязательно: разные серверные модели для уровней Swift / Studio / Deep.
AI_MODEL_SWIFT=
AI_MODEL_STUDIO=
AI_MODEL_DEEP=
```

Ключи не попадают в `dist/`, базу материалов, ответы API или браузер. Второй ключ — только серверный резерв при сбое первого; пользователь не выбирает ключ и не получает к нему доступ.

## Проекты и Nova Actions

Пользователь сначала создаёт проект: у него есть описание, память бренда и тон. Затем он подключает готовый контент-пак или собирает собственный из шагов. Каждый результат сохраняется внутри проекта.

В прототипе уровни генерации списывают внутренний лимит сервиса: `Swift` — 1 Action, `Studio` — 3, `Deep` — 6. Это не перепродаваемые токены AI-провайдера и не доступ к его API.

## Перед публикацией

- замените `support@example.com`, черновые документы и реквизиты на реальные;
- подключите HTTPS, управляемую БД, Redis/rate limit и мониторинг;
- задайте `ADMIN_EMAIL` и уникальный `ADMIN_PASSWORD` до первого запуска;
- проведите проверку политики данных, оферты и категории сервиса у платёжной системы;
- не включайте оплату, пока цены, срок доступа, возвраты и состав тарифов не согласованы.
